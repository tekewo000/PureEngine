# PureEngine

C#で作る、UI中心の2Dマルチプレイゲーム向けエディター。
現在は空のウィンドウを表示する最小構成です。

## 作りたいもの

UI中心のカードゲーム・ボードゲーム・政治や経営の対戦ゲームなどを、
普通のC#で作りやすくする2Dゲームエンジンを目指します。
制作に使うエディターは.NET 11とAvaloniaで、モダンな見た目と使いやすさにこだわります。
ゲーム内UIのデザインは、ゲームの制作者が自由に作れるようにします。

以下は今後の構想であり、まだ実装されていません。

### 普通のC#クラスをアタッチできる

- `MonoBehaviour`や`SyncScript`のような、エンジン専用の基底クラスの継承を必須にしない。
- 通常のC#クラスをゲーム内のオブジェクトにアタッチし、プロパティをエディターで編集・保存できるようにする。
- データを保持するだけのクラスにも対応する。自動更新などが必要な場合だけ、任意のインターフェースなどで実行側と連携する。
- アタッチできることと、毎フレーム更新されることを分けて考える。
- 配札・投票・勝敗判定などのゲームルールは、描画やSteamに依存しないC#として書けるようにする。

ここでの「Pure C#」は、専用の基底クラスに縛られずにゲームコードを書けるという意味です。
描画やSteam連携で利用するライブラリまで、すべてC#のみで実装するという意味ではありません。
アタッチ対象の登録方法、保存対象の指定方法、ライフサイクルの詳細は今後検討します。

### マルチプレイを複数インスタンスで確認できる

- エディターで人数を選び、ホスト1つと複数のクライアントをまとめて起動・停止できるようにする。
- 各ゲームは別プロセスで動かし、起動時に役割・接続先・テスト用プレイヤーIDを渡す。
- ログをホスト・各プレイヤーごとに識別できるようにする。
- ローカルでの複数起動と、Steamを使った接続検証を切り替えられるようにする。
- どちらの接続方法でも、同じゲームルールを使う。

最初は、2つのゲーム画面を一度に起動し、一方のボタン操作の結果がもう一方に反映されることを目標にします。
ローカルの複数起動は、Steamの複数アカウント接続を検証する機能とは分けて扱います。

### Steamで友達と遊べる

- ロビーの作成・招待・参加・退出を扱いやすくする。
- 参加者一覧、準備完了、ゲーム開始の流れを支援する。
- UIそのものではなく、プレイヤーの操作と確定したゲーム状態を通信する。
- ホストが操作を検証し、全員に公開する情報と本人だけに見せる手札などを分けて配信できるようにする。

### UI編集から始め、Spriteにも広げられる

- 画像・文字・ボタンを配置し、位置・サイズ・色などを編集、保存、再読み込みできるようにする。
- プレビューで実際のゲームの見た目と操作を確認できるようにする。
- 将来はSprite、アニメーション、2Dカメラにも対応する。
- UIのレイアウトと、Spriteのゲーム空間での位置・回転・拡大縮小は、それぞれに合った形で扱う。

### 拡張しやすい構成にする

- AvaloniaはエディターのUIに使い、ゲーム実行部分と保存データをAvaloniaから独立させる。
- ゲーム実行部分の描画をエディターのプレビューで表示する。描画技術と埋め込み方法は今後検証する。
- 標準部品と同じ仕組みで、独自のカード表示や投票結果などを追加できるようにする。
- 最初はC#で部品を追加して再ビルドできる形を目指し、必要になったところから拡張する。

## 現在できること

- ダークテーマの空のエディターウィンドウを起動する。
- .NET 11 RC1とAvaloniaでビルドし、Windows上で表示を確認済み。

## 最初の到達点

1. 文字とボタンを配置し、プロパティを編集・保存・再読み込みする。
2. 普通のC#クラスをアタッチし、プレビューでボタン操作に反応させる。
3. ローカルでホストとクライアントを同時起動し、操作の結果を共有する。

## 起動

PowerShellでリポジトリのフォルダを開き、次を実行します。

```powershell
./run-editor.ps1
```

起動スクリプトは `%LOCALAPPDATA%/PureEngine/dotnet/dotnet.exe` があれば使用し、
なければPATH上のdotnetを使用します。

別のPCでは、指定の.NET 11 SDKをインストールしてください。
公式のdotnet-install.ps1で上記のユーザーフォルダへ導入することもできます。

通常のdotnetコマンドが指定SDKを認識する環境では、以下でも起動できます。

```powershell
dotnet run --project PureEngine.Editor
```

## ファイル

- `Program.cs`: 起動処理
- `App.axaml`: アプリ共通のテーマ
- `App.axaml.cs`: メインウィンドウの生成
- `MainWindow.axaml`: ウィンドウの見た目
- `MainWindow.axaml.cs`: ウィンドウの初期化

上記のソースは `PureEngine.Editor/` 内にあります。
ゲーム実行部分・Steam連携・編集機能はまだ実装していません。
